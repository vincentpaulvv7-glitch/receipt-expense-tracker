# 🧾 Receipt & Expense Tracker

An AI-powered web application that analyzes receipt images, extracts expense details, and splits bills among multiple people.

## 🚀 Live Demo

https://receipt-expense-tracker-zxz8anupp8gsdbwlcpitpd.streamlit.app/

## ✨ Features

- 📸 Upload receipt images
- 🤖 Analyze receipts using Google Gemini Vision AI
- 🧾 Extract store name, items, prices, and total amount
- 👥 Split bills among multiple people
- 💰 Calculate the amount each person should pay
- 📄 Generate and download an expense summary

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- GitHub
- Streamlit Community Cloud
